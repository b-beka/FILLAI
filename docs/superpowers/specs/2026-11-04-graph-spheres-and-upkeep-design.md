# Сферы, иконки, анимация стрелки и лёгкая поддержка

## Зачем

FILL AI — для школьников (ЕНТ), студентов, меняющих профессию и учителей. В ближайшие месяцы
сайт просто показывают, бесплатно, на текущем ключе OpenRouter. Показ должен быть надёжным и
запоминающимся: человек вводит тему, стрелка улетает в граф, и знания выстраиваются в понятное
дерево, а не в россыпь курсов вокруг «Вы».

## Цели

1. Стрелка отправки стоит внутри строки ввода; при отправке отделяется и становится новым узлом графа.
2. У каждого узла темы — своя иконка, связанная с темой.
3. Темы вложены: «Языки → Английский, Казахский». Новый курс сам попадает в нужную сферу.
4. Лёгкая поддержка: проверки в GitHub, резервная копия базы, инструкция для типичных сбоев.

## Не цели

- Редактор курсов для учителей (позже; дерево сфер ему не мешает).
- Платный сервер и выкладка на него.
- Ручной перенос курса в другую сферу.
- Платная или другая модель AI.

## Анти-цели

Провал, даже если всё формально работает:

- на показе генерация падает из-за того, что AI не смог определить сферу;
- граф становится нечитаемым из-за обилия узлов;
- в сферах появляются дубли вроде «Языки» и «Иностранные языки».

## Подходы

**Иконки.** Рассмотрены: AI выбирает из набора, AI рисует SVG, эмодзи.
Выбран пользователем: **AI выбирает из набора Lucide**. Единый стиль, бесплатно, безопасно.
SVG отклонён из-за качества и риска вредного кода, эмодзи — из-за конфликта с дизайном Figma.

**Подтемы.** Рассмотрены: AI определяет сам, AI предлагает и человек подтверждает.
Выбран пользователем: **AI определяет сам**. Без лишнего шага перед запуском.

**Поддержка.** Один разумный вариант для бесплатного показа: проверки, копия, инструкция.

## Решения пользователя

- Аудитория: все, кто связан с EdTech (см. «Зачем»).
- Ближайшие месяцы — показ, бесплатно, бесплатного API хватит.
- Иконки и подтемы — как в разделе «Подходы».
- Стрелка внутри строки, отделяется и добавляется к графу.

## Как устроено (решения исполнителя, можно поправить)

### Данные

- `categories`: добавить `parent_id` (ссылка на `categories.id`, nullable) и `icon` (строка, nullable).
  Сфера — запись без родителя, подтема — запись с родителем. Миграция через alembic, RLS не меняется.
- Категории общие для всех пользователей, чтобы модель переиспользовала их и не плодила дубли.
  В графе показываются только те, где есть курсы пользователя.
- Глубина строго две: сфера → подтема. Курс привязан к подтеме.
- `CourseResponse` начинает отдавать `category` с `label`, `icon` и родителем.

### Определение сферы

- Новый небольшой шаг в генерации `generate_course` вместо `_determine_category`: модель получает
  тему и список существующих сфер с подтемами, возвращает JSON `{sphere, sphere_icon, subtopic, subtopic_icon}`.
- Имена иконок проверяются по белому списку. Неизвестное имя заменяется на `book`.
- Сравнение сфер без учёта регистра и пробелов, чтобы не появлялись дубли.
- Любая ошибка шага (сбой, лимит, плохой JSON) **не роняет генерацию**: курс уходит в сферу «Общее».
- Стартовые сферы создаются миграцией: Языки, ЕНТ, Программирование, Дизайн, Наука, Профессия, Общее.

### Иконки

- Зависимость `lucide-react` в версии с точной фиксацией и список примерно из 150 тематических иконок
  (`frontend/src/lib/topicIcons.ts`). Тот же список имён — в бэкенде, тест проверяет совпадение.

### Граф

- Дерево: Вы → сфера → подтема → курс → модули.
- Подтема с одним курсом сливается с курсом в один узел, чтобы не плодить звенья.
- Модули показываются только у выбранного курса. Сейчас показаны у всех, в дереве это перегрузит граф.
- Для узла подтемы или курса используется иконка подтемы, для сферы — иконка сферы.
- Пустой граф и подсказки остаются как есть.

### Стрелка

- Кнопка отправки переезжает в строку ввода, справа, рядом с «+». Строка остаётся по центру.
- При отправке копия стрелки летит из строки к экранной позиции нового узла (около 700 мс), затем
  на этом месте появляется узел «Собираю курс…». В строке стрелка возвращается плавно.
- Если человек не вошёл: сразу переход на вход, без полёта.
- При `prefers-reduced-motion` полёта нет, узел появляется сразу.

### Поддержка

- `.github/workflows/deploy.yml` заменяется на `ci.yml`: pytest на SQLite, проверка типов и сборка
  фронтенда, на актуальных версиях actions. Шаги выкладки-заглушки убираются.
- `backend/scripts/backup_db.py` и `restore_db.py`: выгрузка всех таблиц в сжатый JSON
  в `backend/backups/` (в `.gitignore`), потому что `pg_dump` на компьютере нет.
  В копии есть хеши паролей, поэтому она остаётся только локально.
- `/health` дополнительно проверяет соединение с базой.
- Понятное сообщение, если OpenRouter ответил лимитом (429).
- Лимит 5 генераций мешает показам: аккаунту Bekzhan выдаётся роль `admin`, у неё лимита нет.
- `docs/RUNBOOK.md`: запуск, копия и восстановление, Supabase на паузе, кончился лимит, замена ключа.

## Проверка

- Тесты: определение сферы (переиспользование, новая сфера, сбой модели → «Общее», неизвестная иконка),
  миграция на чистой базе, совпадение списков иконок.
- Вручную в браузере: две темы одной сферы (английский и казахский) попадают под «Языки», стрелка
  долетает до узла, все три темы оформления, мобильная ширина.

## Оставлено исполнителю

Подбор 150 иконок, точная траектория и кривая анимации, текст промпта определения сферы.
