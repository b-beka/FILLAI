# FILL AI — план

## Главная идея

Пользователь пишет тему в строке «Изучить» → AI собирает мини-курс (15–30 минут):
конспект, тесты, задания, подобранные YouTube-видео и трекер прогресса.
Знания пользователя показываются как **граф**: в центре — сам пользователь,
ветки — его запросы (Языки → RU / EN, Тренировки, Дизайн), листья — разделы курса
(Теория · Видео · Задание). Курсами можно делиться (Сообщество — маркетплейс курсов,
Друзья — общие графы), а Библиотека хранит историю.

Источники: презентация «Где искать (2).pdf» и макет Figma `q8zGZdZc8aHSZ2Skp8uCXK`.

## Дизайн (по Figma, кадр 1728×1117)

| Токен | Значение |
|---|---|
| Шрифт | Montserrat 300/400/500 |
| Сайдбар | `#202020`, ширина 375 (≈22%), строки 65px, иконки 30px, текст 20px |
| Разделитель | `#464646`, 1px |
| Фон холста | диагональный градиент `#303030 → #6a6a6a → #303030` |
| Узел графа | круг, градиент `#a8a8a8 → #5a5a5a`, центр 100px, ветки 80px, иконки светлые |
| Связи | белые линии 6px |
| Строка «Изучить» | `#d9d9d9`, 676×58, радиус 29, лупа слева, «+» справа, кнопка «>» 40px |
| Панель «Тренировки» | 320×370, радиус 30, полупрозрачный серый градиент, 3 пункта с круглыми иконками 60px, 3 маленьких действия 30px (календарь, прогресс, поделиться) |
| Прогресс | концентрические кольца `#3a3a3a / #4a4a4a / #bdbdbd` вокруг узла пользователя |
| Светлая тема | сайдбар `#f5f5f5`, фон `#eaeaea → #bcbcbc`, узлы белые |

«Живой» граф (из прототипа living-graph-ui): узлы покачиваются (±4px), отталкиваются от курсора
(радиус 170), перетаскиваются и пружиной возвращаются на место из макета; фон смещается за курсором.
При `prefers-reduced-motion` движение отключено.

Экраны:
1. **Главная (граф)** — пустой граф «пользователь + 3 ветки», строка «Изучить».
2. **Граф с курсом** — ветка раскрыта, справа панель «Тренировки».
3. **Прогресс** — кольца уровня владения навыком.
4. **Друзья** — два графа, соединённых общей темой.
5. **Библиотека / Сообщество / Профиль** — тот же каркас, контент в центре.
6. **Курс** — открывается из панели: Теория (конспект), Видео, Задание, Тесты.

## Бэкенд (FastAPI, уже есть)

Используем как есть:
- `POST /api/auth/register`, `POST /api/auth/login/json`, `GET /api/auth/me`
- `POST /api/courses/generate` — мультиагентная генерация (структура → уроки → видео → паспорт)
- `GET /api/courses/my`, `GET /api/courses/my/{id}`, `GET /api/courses` (публичные — Сообщество)
- `POST /api/courses/generate-module-test` — тесты по модулю
- `POST /api/ai/grade-exercise` — проверка заданий
- `POST /api/progress/lesson/{id}/complete`, `GET /api/progress/course/{id}`

Сделано при чистке: удалены дубль `/api/ai/grade-exercise`, неавторизованный
`/generate/batch`, отладочные скрипты.

Дальше (по приоритету):
1. **Друзья** — таблица `friendships` + `GET/POST /api/friends`; сейчас экран-заглушка.
2. **Ссылка на курс** — `share_link` уже есть в модели, нужен `POST /api/courses/{id}/share`.
3. **Экспорт в PDF / Telegram-бот** — из презентации, после MVP.
4. **Быстрый режим генерации** — ответ за 5–7 минут: стриминг прогресса (SSE) вместо одного долгого запроса.
5. **Оплата (CloudPayments)** — код есть, в интерфейсе не показывается до появления тарифов.
