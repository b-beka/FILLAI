## 🚀 Следующие шаги для запуска MVP

1. **Настроить базу данных:**
   ```bash
   cd backend
   # Создать .env файл с DATABASE_URL
   alembic upgrade head
   ```

2. **Настроить email сервис:**
   - Зарегистрироваться на Resend.com
   - Получить API ключ
   - Добавить в .env: `RESEND_API_KEY=...`

3. **Настроить Sentry (опционально):**
   - Создать проект на sentry.io
   - Добавить DSN в переменные окружения

4. **Деплой:**
   - Следовать инструкциям в DEPLOYMENT.md
   - Настроить переменные окружения на платформе
   - Проверить работу всех функций

5. **Тестирование:**
   ```bash
   cd backend
   pytest tests/
   ```
